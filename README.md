# Домашнее задание к работе 8
## Описание
### Вариант 6
Вычислить значение ряда для заданных пользователем значений a и n
## 1. Алгоритм и блок-схема 
### Алгоритм 
1. Объявить целые переменные a и n, а также счетчик цикла i.
2. Объявить вещественную переменную product (произведение) и инициализировать её значением 1.0.
3. Запросить у пользователя ввод значений a и n.
4. Запустить цикл for от i = 1 до n.
5. Внутри цикла умножить текущее значение product на очередной член ряда: (a - i * n).
6. Вывести итоговое значение product на экран (Конец).

## 2. Реализация программы
```c
﻿#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    int a, n, i;
    double product = 1.0; 

    printf("Введите a: ");
    scanf("%d", &a);
    printf("Введите n: ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++) {

        double ni = (double)i;

        product = product * (a - ni * n);
    }

    printf("Результат: %.2f\n", product);

    return 0;
}
```
